Raw LS-DYNA ASCII output from the run documented in the top-level README.

| File | Contents |
|---|---|
| `glstat` | global energies, time step, added mass |
| `matsum` | energy per part |
| `rcforc` | contact interface forces |
| `sleout` | contact energy per interface |
| `lsrun.out.txt` | solver log and timing |
| `figures/` | plots generated by `scripts/plot_results.py` |
| `screenshots/` | LS-PrePost views of the model and the final crimp |
| `animations/` | forming animation |

Host name and input path in `lsrun.out.txt` are replaced with `[redacted]`;
nothing else in the solver output is edited. `ncforc` is not committed (63 MB).
